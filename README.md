Personal Finance Tracker

Personal Finance Tracker is a Java-based application designed to help students and individuals manage their personal finances by recording income and expenses, tracking spending habits, and monitoring their current balance.

The project was developed using object-oriented programming principles and provides a simple console-based interface for managing financial transactions.

Features:
- Income Tracking
- Add income transactions
- Record income source categories
- Track earnings over time
- Expense Tracking
- Add expense transactions
- Categorise spending
- Record transaction descriptions
- Transaction History
- View all recorded transactions
- Display complete transaction details
- Maintain a financial activity log
- Balance Calculation
- Automatically calculate current balance
- Add income values
- Deduct expense values
- Display real-time financial position

Technologies used:
- Java
- Object-Oriented Programming (OOP)
- ArrayLists
- Scanner Class
- IntelliJ IDEA
- Git & GitHub
- Project Structure
